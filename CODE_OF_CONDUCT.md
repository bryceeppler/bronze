# Code of conduct

Bronze follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

## The short version

Be kind and assume good faith.
Critique code and ideas, never people.
No harassment, insults, sexual content, or publishing anyone's private details.
This applies in the issues, pull requests and anywhere else you speak for the project.

## Reporting

Report conduct privately through [GitHub's private reporting](https://github.com/bryceeppler/bronze/security/advisories/new) and start the title with "Conduct".
Only the maintainer sees it, and every report gets a reply.
The maintainer may edit or remove comments, and warn or ban anyone who breaks this code, as the Contributor Covenant's enforcement guidelines describe.
