# Logo directions

Four candidates to replace the current mark and wordmark.
Each folder holds the same set: `logo`, `mark` and `wordmark` for light and dark backgrounds, and `icon` tiles on the same 824-unit grid as `icon/icon-*.svg`.
Once one is picked, it moves up to `assets/brand`, `python3 assets/brand/build.py` regenerates every icon, and this folder goes away.

| Direction | Mark | Wordmark |
| --- | --- | --- |
| `medal` | The app's checked box, struck as a bronze medal | Fraunces SemiBold, outlined |
| `highlight` | A line of selected text with a caret, the moment of capture | Geist SemiBold, outlined |
| `ingot` | A bar of bronze, the material the app is named for | Unbounded SemiBold capitals, outlined |
| `keycap` | A Shift key cast in bronze, since double-tapping Shift captures | Geist Mono Medium, outlined |

All four fonts are under the SIL Open Font License, and every wordmark is outlined to paths, so none needs a font installed.
